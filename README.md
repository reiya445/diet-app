# 🎯 ペナルティーアプリ（Penalty App）

目標達成をサポートする、楽しいペナルティー＆ご褒美アプリです！  
日々の目標に対して、達成時はご褒美を、失敗時はペナルティーをランダムに獲得できます。🎉

**リンク**: https://github.com/reiya445/diet-app

---

## 📋 概要

ダイエットや自己改善の目標達成を応援するWebアプリケーションです。
- 📅 **今日・今週・今月**の3段階の目標を設定できます
- ✅ 目標達成時と失敗時にボタンをクリック
- 🎰 ランダムに**ご褒美**または**罰ゲーム**が表示されます
- 💾 ブラウザのLocalStorageに自動保存

## ✨ 主な機能

### 🏠 ホーム画面（メイン画面）
```
┌─────────────────────────────────┐
│    🎯 ペナルティーアプリ         │
│  目標達成を目指そう！             │
├─────────────────────────────────┤
│                                 │
│  📅 今日の目標                   │
│  ［目標内容］                    │
│  [✅ 達成] [❌ 失敗]             │
│                                 │
│  📊 今週の目標                   │
│  ［目標内容］                    │
│  [✅ 達成] [❌ 失敗]             │
│                                 │
│  📈 今月の目標                   │
│  ［目標内容］                    │
│  [✅ 達成] [❌ 失敗]             │
│                                 │
├─────────────────────────────────┤
│ [🎯 目標設定] [⚠️ 罰ゲーム]    │
│ [🎁 ご褒美]   [📸 カロリー計算] │
└─────────────────────────────────┘
```

### 🎯 目標設定画面
- 3つの期間（今日・今週・今月）から選択
- 各期間の目標を自由に設定・編集
- 設定した目標はホーム画面に表示

### ⚠️ 罰ゲーム設定画面
- 失敗時に実行する罰ゲームを複数登録
- 例：スクワット30回、冷たいシャワー、好物禁止 など
- ボタンをクリック時にランダムに1つ選ばれます

### 🎁 ご褒美設定画面
- 達成時に得られるご褒美を複数登録
- 例：好きなケーキを食べる、好きなドラマを1時間見る など
- ボタンをクリック時にランダムに1つ選ばれます

### 📸 カロリー計算画面
- 食事の写真からカロリー自動計算（開発中）
- 現在は手動で食事情報を記録可能

## 🚀 クイックスタート

### 必要な環境
- Node.js 14 以上
- npm または yarn

### インストール手順

```bash
# リポジトリをクローン
git clone https://github.com/reiya445/diet-app.git
cd diet-app

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm start
```

ブラウザが自動的に開き、**http://localhost:3000** でアプリが表示されます。

## 💾 データ保存

アプリは以下のデータを **LocalStorage** に自動保存します：

```javascript
// 保存されるデータ例
{
  "goals": {
    "today": { "title": "3000kcal以下に抑える", "completed": false },
    "week": { "title": "毎日30分運動する", "completed": false },
    "month": { "title": "5kg体重を減らす", "completed": false }
  },
  "penalties": ["スクワット30回", "冷たいシャワー", ...],
  "rewards": ["好きなケーキを食べる", "好きなドラマを見る", ...]
}
```

ブラウザのキャッシュをクリアすると、データが削除されます。

## 🎮 使い方

### 基本的な流れ

1. **最初に設定**
   - 🎯 「目標設定」で今日・今週・今月の目標を入力
   - ⚠️ 「罰ゲーム」で失敗時のペナルティーを登録（3個以上推奨）
   - 🎁 「ご褒美」で達成時のご褒美を登録（3個以上推奨）

2. **毎日使用**
   - ホーム画面で目標の達成/失敗をマーク
   - ボタンをクリック時にご褒美or罰ゲームが表示される
   - 楽しみながら目標達成を目指す！

3. **随時更新**
   - 目標の内容を変更したい場合は「目標設定」で変更
   - 罰ゲームやご褒美を追加・削除したい場合も対応

## 📝 設定画面での操作

### 🎯 目標設定
- 期間を選択（今日・今週・今月）
- 目標内容を入力

### ⚠️ 罰ゲーム設定
- 罰ゲーム内容を入力
- 「罰ゲームを追加」ボタンをクリック

- 削除ボタン（🗑️）で削除可能

### 🎁 ご褒美設定
- ご褒美内容を入力
- 「ご褒美を追加」ボタンをクリック
- 複数個登録可能
- 削除ボタン（🗑️）で削除可能

## 🐛 トラブルシューティング

### `npm install` でエラーが出た場合
```bash
# キャッシュをクリアして再度インストール
npm cache clean --force
npm install
```

### アプリが起動しない場合
```bash
# Node.jsバージョンを確認（14以上推奨）
node --version

# ポート3000が使用中の場合
PORT=3001 npm start
```

### 設定がリセットされた場合
- ブラウザの開発者ツール → Application → LocalStorage
- "http://localhost:3000" の項目をクリア
