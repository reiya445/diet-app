# 🎯 ペナルティーアプリ

目標達成をサポートし、成功時にはご褒美を、失敗時には罰ゲームが得られるアプリです。

## 機能

### 🏠 ホーム画面
- 📅 **今日の目標**: 日々の目標表示と達成/失敗判定
- 📊 **今週の目標**: 週単位の目標管理
- 📈 **今月の目標**: 月単位の目標管理
- **達成/失敗ボタン**: ボタンをクリックするとランダムにご褒美または罰ゲームが表示されます

### ⚙️ 設定画面

#### 🎯 目標設定
- 3つの期間（今日・今週・今月）から目標を設定
- 各期間ごとに異なる目標を管理可能

#### ⚠️ 罰ゲーム設定
- 失敗時に実行する罰ゲームを複数登録
- ランダムに選ばれた罰ゲームが表示されます

#### 🎁 ご褒美設定
- 達成時に得られるご褒美を複数登録
- ランダムに選ばれたご褒美が表示されます

#### 📸 カロリー計算（開発中）
- 食事の写真からカロリー計算する機能
- 現在は手動でカロリー情報を記録できます

## 技術スタック

- **フロントエンド**: React 18
- **スタイリング**: Tailwind CSS
- **ストレージ**: LocalStorage（ブラウザローカル保存）
- **言語**: JavaScript/JSX

## セットアップ方法

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm start

# ブラウザで自動的に http://localhost:3000 が開きます
```

## 使い方

1. **ホーム画面**で目標の達成/失敗をマークする
2. 結果に応じてご褒美または罰ゲームが表示される
3. **設定画面**から目標・罰ゲーム・ご褒美を管理
4. 食事を記録してカロリー管理（手動入力）
